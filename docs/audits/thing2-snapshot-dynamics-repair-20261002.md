# Thing 2 snapshot direction and coupling repair

This batch repairs the existing domain-to-Civilization observation path. It preserves all native brain controllers, phase eligibility rules, anatomical mappings, Thing 1 code and callers, numerical financial kernels, and immune routing. The companion JSON contains source hashes, the 20-domain controller inventory, and verification evidence.

## Concrete repairs

The provisional adapter previously added a stress sample whenever a reader called update. Repeated reads of one snapshot could therefore manufacture persistence, variance history, and consecutive structural-break confirmations. It now records each increasing signal-engine snapshot timestamp once. Replayed snapshots do not add samples or confirmations. Older snapshots, conflicting values at the same timestamp, missing/invalid observations, and missing/future timestamps produce an unavailable annotation without deleting previous valid history. Valid subsequent snapshots recover normally.

Snapshot update time is explicitly identified as such. It is not a verified publisher observation date, and separate snapshot revisions can still contain the same upstream evidence. This repair does not claim that a cache refresh constitutes an independent observation.

The old trajectory calculation ranked phase labels as distress levels. In that ordering, P3 to P4 could be called escalating even while stress declined. The replacement reads the sign of the difference between the last two distinct stress snapshots. Rising stress is ESCALATING, falling stress is DECLINING, and equal stress is STABLE. This is an observation direction, not a universal phase-transition law or forecast. Existing provisional classification conditions remain unchanged.

Cross-domain pressure retains its existing weighted formula and hub normalization. An explicit zero confidence now multiplies the contribution by zero instead of being replaced with 0.5. Missing or invalid confidence, severity, or neighboring stress supplies no invented contribution. Repeated copies of the same neighbor within one pattern are counted once. Distinct patterns remain separate evidence. No new coupling coefficient is adopted.

The brain bridge previously forwarded cached kernelPhase, kernelTrajectory and kernelCAccum even after the native producer changed phaseSource to fallback. It now forwards those three Thing 2 fields only while the producer identifies a current Thing 2 kernel result. A failed result clears those fields in the decision input and cached bridge payload. Native phase, diagnoses, treatments, stress and cognition mirroring remain available; a subsequent valid kernel result recovers.

## Existing domain variables identified

All 20 native domain implementations contain a regulation servo. Each has a measured/computed inhibition read, a drive/deviation-derived target, an error, a bounded discrete integral, and an emission-confidence effector. The inventory records each owning file, function, state key and source hash. These controllers already have a purpose and are retained.

| Candidate concept | Existing native servo observation | Remaining distinction |
| --- | --- | --- |
| State x | Regulation inhibition | This is a controller subsystem read, not the domain's physical stress plant. |
| Reference s | Drive/deviation-derived inhibition target | The adaptive stress baseline and handoff floor are other quantities; they cannot simply replace this target. |
| Error e = x − s | Native error is target − inhibition | The native convention is the negative of candidate e. Its positive braking control is consistent with that convention; it is not a wrong-sign defect by itself. |
| Compensation y | Bounded discrete integral of native error | Cycle-step accumulation and saturation differ from the candidate continuous-time integral. No continuous time scale has been identified. |
| Effector | Bounded proportional reduction of emitted confidence | This does not establish actuation of the measured physical stress variable. |
| External support u and operating load d | No separate identification established in this pass | They cannot be manufactured from phase labels, neighbor pressure, or financing receipts. |
| Reserve h(y) | Not identified | Native integral magnitude is not automatically physiological or financial reserve. |
| Angular coupling K_ij(y) | Existing label-based routing coefficients | A phase category is not an oscillator angle; these coefficients do not establish the candidate angular coupling law. |

The full candidate regulation model is therefore not installed by this batch. The inventory makes the next experimental implementation concrete: choose an existing owning controlled variable and effector, preserve its sign convention and cycle timing, identify external inputs separately, and prove its feedback response before claiming the continuous candidate plant or scaffold-withdrawal contract is represented.
