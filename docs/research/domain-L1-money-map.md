## The one instrument (all 20 are the same machine)
`ingest free public feed -> entity-resolve + rank/join (THE MOAT) -> curated plain-language readout -> auto-drip newsletter (affiliate-monetized) -> paid scoped alert -> licensed feed`. Built once on the existing P3 desk spine (signal -> rank -> counterparty -> ingest -> desk -> cron) + the `build`/`audit`/`verify`/`ship` skills. Reskin per domain; only the ranking function and re-voicing prompts change. Sell CURATION of public signal, never raw data. Own-nothing. The recurring-affiliate side-rail (newsletter platforms: Kit/ConvertKit 30% recurring, ActiveCampaign ~30%, beehiiv up to 60% first-year) earns before any subscriber converts.

## Legal/trust gates (the irreducible cores)
- **Defense**: public unclassified AWARD-finance data ONLY; civilian/analyst buyers; nothing ITAR/EAR/classified.
- **Intelligence**: OSINT/open-source only; no classified, no surveillance-of-individuals; false-positive sanction-match = liability (human confirm before high-severity fire).
- **Law**: NOT legal advice (UPL wall); descriptive filing summaries only; buyers = firms/finance, never pro-se.
- **Medicine**: NOT clinical advice; FAERS = correlation-not-causation caveat mandatory; the FEED to mass-tort/insurers is the live L1 (Recall Shield stays parked).
- **Finance**: NO investment advice, no retail; sell distress-signal curation to professional counterparties; a false going-concern flag = reputational death (audit gate non-optional).
- **Population**: aggregate-only, never re-identify.
- **Governance**: strict non-partisan neutrality; entity-resolution errors = defamation.
- **Religion**: neutrality/sensitivity; instruments and numbers, never doctrine; lowest fit.
- **Environment/Infrastructure**: "violation" != "guilt"; strictly descriptive with source links; no engineering/failure certification (defamation + causation walls).
- **Agriculture/Economy/Energy**: descriptive readout, not trade/rate recommendation that carries advisory liability.

## Fattest-wallet convergence (sequence L1s that share a buyer)
- **Mass-tort plaintiff firms + litigation finance** (pay PER SIGNED CASE): Medicine + Law + Environment-L3 all feed this ONE wallet. Warmest across all 20.
- **Distressed-debt / claims-trading firms**: Finance + Industry (WARN distress) + Infrastructure.
- **Staffing / recruiters**: Technology + Industry.
- **ESG / insurers / procurement**: Environment-L2/L3 + Infrastructure.
- **RE investors / site-selection**: Population + Agriculture + Economy.

## Recommended bootstrap order (no-capital scales first, then compounds)
Deploy the domains with a LIVE desk first (near-zero marginal render cost), let each L1's affiliate + subscription fund the next:
1. **Technology** (desk live, recruiters, cleanest legal) -> first cash.
2. **Medicine** (desk live) + **Law** (free RECAP) -> SAME mass-tort wallet, sequence together = biggest early wallet.
3. **Finance** (kernel+EDGAR live) -> distressed-debt firms, tightest legal gate (audit).
4. **Industry** (WARN adapters partly built) -> staffing, strongest buyer-ROI clarity.
5. **Trade / Science / Defense / Agriculture** -> all free no-auth data, priced-out buyers, high confidence.
6. Fill the rest; **Environment** run as loss-leader L1 that exists to reach its high-value L2 ESG/plaintiff buyers; **Religion/Culture** lowest priority.

L1 (no capital) funds L2 (minimal: domain + Resend/SMS + light compute + Redis auth) funds L3 (moderate: licensed API/data-room feed, priced against GovWin/Bloomberg Government $7.5-14k/yr comps). Same compounding self-funding ladder as `capital-ladder-bootstrap`.
