Nothing on this page publishes anything. It calls the preview path only. Posting happens from /api/social-cron?post=1, which is a separate explicit action, capped per day, and every published post records an ID so it can be deleted. A domain marked would skip has no live data for its claim right now, or its text ran past the 300-character limit. It is skipped rather than padded or trimmed, because a post that invents a number to fill a template is worse than no post. Each post links to the domain page that shows the source behind its figure.
