OPERATOR SOP

Standard Operating Procedure — Daily Workflow

DAILY WORKFLOW

1.Check domain console. Open your assigned domain. Review stress level, active diagnoses, and feed freshness.
2.Review opportunities. Click OPERATOR. Scan Top Money Plays and Action Queue. Note which are new since yesterday.
3.Review economics. Check compensation on each opportunity. Understand the estimated payout before claiming.
4.Claim opportunity. Click CLAIM. Read the terms. Check the acceptance box. Confirm.
5.Execute checklist. Open the workspace (GRANT, PATENT, LOAN, BUSINESS, or INVEST). Follow step-by-step instructions. Complete every section.
6.Submit for review. Mark sections complete. Update status to submitted. Ensure all required documents are ready.
7.Pass audit gate. Auditor reviews your work. If approved, proceed. If rejected, read the reason, fix the issue, resubmit.
8.Execute. File the grant, submit the patent, close the loan, execute the trade, or launch the business.
9.Record outcome. Click RECORD OUTCOME. Select result (SUCCESS / PARTIAL / FAIL / ABANDONED). Enter final value. Add notes.
10.Close claim. Claim becomes read-only. Payout estimate finalized. Performance memory updated.

WEEKLY REVIEW

Check execution memory. Review your success rate, average cycle time, and weakest execution type. Improve where needed.
Check claim ledger. Ensure no claims are stuck in limbo. Update statuses. Close anything abandoned.
Check portfolio. If you have launched companies, review their status. Update notes.

ESCALATION

If auditor rejects without clear reason → submit dispute via Policy & Procedures.
If feeds are stale or broken → note in claim and proceed with available data. Mark confidence as reduced.
If compensation seems incorrect → compare with Execution Framework and Policy.
